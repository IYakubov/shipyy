NAVAL DUEL — Networked Edition (v2)
===================================

A 2-player top-down ship battle. One screen (PC, TV, laptop) shows the
battle. Two players connect from their phones and steer with a ship's
wheel + fire buttons.

REQUIREMENTS
------------
Node.js 16 or newer.

SETUP
-----
    npm install
    npm start
    -> NAVAL DUEL server running on http://localhost:3002

HOW TO PLAY
-----------
1. On the big screen open http://localhost:3002 and pick 1 PLAYER (you vs
   the bot) or 2 PLAYERS (phone vs phone). Keys 1 / 2 work too.
   The lobby shows only a QR code (generated by the server). If the host
   page is on localhost, the QR uses this computer's LAN IP so phones on
   the same Wi-Fi can reach it. The room number is shown small, top right.
2. Each phone scans the QR (or opens /controller.html and types the room
   number). First phone = Player A (ink), second = Player B (navy).
   In 1-player mode only one phone can join; the bot sails Player B's ship.
3. Tap READY (both phones in 2P). A 3-2-1 countdown runs, then the battle
   starts. If a needed phone disconnects, the battle pauses until it's back.
4. When a ship sinks, the end menu (Rematch / Back to lobby) appears on the
   big screen and on both phones. Tap an item on a phone to choose it.
   Input is locked for 0.9 s after the menu opens. The host also accepts
   arrow keys + Enter and the mouse. Back to lobby keeps the phones
   connected and resets Ready.

CONTROLS (phone, LANDSCAPE)
---------------------------
- Ship's wheel (left): drag your finger around the dial to turn it.
  Turning it steers the ship. Touching the wheel at all makes the ship
  sail forward at a steady speed; let go and it glides to a stop.
- MACHINE GUN (right, big button): hold to fire straight ahead from the bow.
  The face inverts and the ring spins while firing.
- TORPEDOES (right, upper button): tap to launch a 3-torpedo spread off the
  port (left) side. A sweep shows the 3.6 s reload; it pings when READY.
- Holding the phone upright on the battle screen shows a "turn sideways"
  prompt. Light haptics on presses.

1-PLAYER MODE (THE BOT)
-----------------------
The bot drives ship B through the same inputs a phone sends (wheel angle,
thrust, gun held, torpedo), so it has exactly your speed, turn rate,
weapons and cooldowns. It hunts you with the bow gun (leading your
movement), sets up port-side torpedo broadsides, swerves away from your
torpedoes, backs off when you get too close, and steers clear of walls.
- Win → "Next battle" at the next level. Lose → "Try again" at the same
  level. Back to lobby resets to level 1. Best level is kept in the host
  browser (localStorage navalduel_best).
- Each level the bot reacts faster (300 → 120 ms), aims tighter, leads
  better, shoots from further, uses torpedoes and dodges more often.
  It reaches full strength at level 5. Tune in botParams() in index.html.
- In tests: level 1 sinks a player sailing in circles in ~80 s, level 5
  in ~25 s.

GAMEPLAY (unchanged)
--------------------
- 6 HP. 10 machine-gun hits = 1 HP (the next HP segment drains as hits
  land). Torpedo hit = 2 HP. First ship sunk loses.

ONE PHONE, ONE SLOT
-------------------
Each phone keeps a clientId in localStorage (navalduel_client). Opening the
link again on the same phone keeps the same slot and the old tab shows
"Opened on another tab". Auto-join waits until the page is visible (QR
scanner previews can't grab a slot). The slot is always read from the
server socket, never trusted from the payload. A phone that reloads
mid-match goes back to its ship.

DESIGN
------
Same language as Tank War / Math Duel / Counting Clash: Unbounded variable
font bundled in public/fonts/ (OFL.txt), soil #cfcdc6, slab #dddbd4,
paper #ecebe6, ink #1b1b1a, Player B navy #1A4361. No glow, no noise.

SOCKET PROTOCOL
---------------
create_game {mode,origin,base} -> game_created {code,mode,joinUrl,qrSvg}
join_game / rejoin_game {code, clientId} -> joined {slot,code,mode} | join_error
replaced                                   server -> old phone tab
player_ready                               phone -> server
lobby_update {mode,A,B,readyA,readyB}      server -> all
game_start                                 server -> host + phones
ctrl_wheel {angle, thrust}                 phone -> host (every 40 ms)
ctrl_gun                                   phone -> host (every 150 ms held)
ctrl_torpedo                               phone -> host
host_ui {code, ui:{menu,eyebrow,title,winner,items,focus,locked}|null}
                                           host -> server -> phones
ctrl_menu {index}                          phone -> host
restart_game {code}                        host -> server (rematch)
host_back_to_lobby {code} -> back_to_lobby host -> server -> phones
player_left, player_joined, host_disconnected

PROJECT STRUCTURE
-----------------
server.js               Express + Socket.io (rooms, QR, slots, relay)
public/index.html       Host display (sounds embedded as base64)
public/controller.html  Phone controller
public/assets/          Wheel dial + wheel (recoloured via currentColor)
public/fonts/           Unbounded + licence
